Deepfake Detection System Using Deep Learning

Developed an AI-powered Deepfake Detection System using Python, TensorFlow, and MobileNetV2 to identify whether an image is Real or AI-generated/Manipulated (Fake). The system uses deep learning and transfer learning techniques to analyze image features and classify suspicious images.

The model was trained and evaluated using a dataset containing real and fake images, achieving **92.01% test accuracy**. Integrated an interactive Gradio interface that allows users to upload images and receive instant predictions with confidence scores.

**Technologies Used:** Python, TensorFlow, Keras, MobileNetV2, OpenCV, Google Colab, Gradio.

**Key Features:**

* Real and fake image classification.
* Deep learning-based image analysis.
* Confidence score for predictions.
* Interactive web-based user interface.
* Fast image prediction.
